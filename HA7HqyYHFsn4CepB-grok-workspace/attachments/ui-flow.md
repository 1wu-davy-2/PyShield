# PyShield 页面交互流程说明（用于生成原型图）

本文档描述 PyShield 加密构建器的全部界面、状态与交互，供 UI 原型工具（Grok / Kimi / Figma AI 等）直接生成高保真原型。

**阅读顺序**：先看第 2 节状态机，再看第 4 节逐屏说明，最后按第 7 节的原型清单出图。
**给 AI 的一句话**：这是一个 Windows 桌面工具（1440×920，无系统标题栏，自绘窗口按钮），左侧固定侧栏 + 右侧内容区，主色为靛蓝 `#4B63E8`，语言为简体中文。

---

## 1. 产品与用户

PyShield 把 Django 项目的 Python 源码加密成不可读的 stub，用户在自己的机器上一键构建受保护副本。

| 角色 | 场景 | 关注点 |
| --- | --- | --- |
| 首次使用者 | 从官网/群文件下载 exe，第一次打开 | 这是什么、能免费用吗、怎么开始 |
| 试用用户 | 已申请 14 天试用 | 还剩几天、还能构建几次、怎么升级 |
| 付费用户 | 已导入专业版/企业版授权 | 快速构建、配额、产物签发 |
| 开发者（内部） | 源码运行 / `PYSHELD_DEV=1` | 不限构建、调试 |

## 2. 授权状态机（决定所有页面的显示）

```
未激活 ──申请试用──► 试用中 ──额度用尽/到期──► 试用已结束 ──购买──► 专业版
   │                    │                                        ▲
   └────导入授权─────────┴──────────导入/激活授权─────────────────┘
```

| 状态 | 顶栏胶囊 | 首屏落地 | 构建按钮 | 版本页主按钮 |
| --- | --- | --- | --- | --- |
| **未激活** | 未激活（琥珀） | 版本与试用 | 点击后跳版本页并提示 | 申请 14 天试用（可用） |
| **试用中** | 试用 · 12 天（琥珀） | 上次停留页 | 可用，剩 3 次 | 重新打开官网 |
| **试用已结束** | 授权异常（红） | 版本与试用 + 弹窗 | 点击弹「试用已结束」 | 免费版置灰「试用已结束」，专业版高亮 |
| **专业版** | 专业版（绿） | 工作区 | 可用 | 免费版置灰「已具备正式授权」 |
| **企业版** | 企业版（绿） | 工作区 | 可用 | 免费版置灰「已具备正式授权」 |
| **开发模式** | 开发模式（琥珀） | 工作区 | 不限次 | 免费版置灰「已具备正式授权」 |

版本页顶部还有一条**试用横幅**（只在工作区出现）：试用中显示剩余天数/次数，未激活显示「尚未激活，先申请 14 天免费试用再开始构建」，已结束显示「试用额度已用完，购买专业版后可继续构建」。

**关键交互**

| 操作 | 结果 |
| --- | --- |
| 选择项目目录 | 自动统计模块数、自动建议输出目录（`<项目名>-shielded`） |
| 切换算法/完整性 | 右侧摘要实时更新；试用状态下不适用的选项置灰并挂 `Pro` 标签 |
| 点击「开始加密」 | 右侧出现进度条 + 阶段文字 + 实时日志；按钮变为「取消构建」 |
| 构建成功 | 绿色结果横幅：模块数/体积/耗时 + 「打开输出目录」「查看构建密钥」 |
| 构建失败 | 红色横幅 + 失败原因 + 日志滚动到底部 |
| 取消构建 | 阶段变为「正在取消」，按钮禁用，结束后状态为「已取消」 |
| 未激活时点击构建 | 跳转到版本与试用并提示「请先申请试用或导入授权」 |

**试用横幅**（页面最上方，仅未激活/试用/结束时出现）
- 未激活：`[未激活] 尚未激活，先申请 14 天免费试用再开始构建  [去申请]`
- 试用中：`[试用版] 试用版 · 剩余 12 天 · 剩余 2 次构建  [升级版本]`
- 已结束：`[试用已结束] 试用额度已用完，购买专业版后可继续构建  [去申请]`

## 5. 关键流程时序

### 5.1 首次启动 → 申请试用 → 回到应用

```
用户            桌面应用                本地/线上授权站点        浏览器
 │ 双击 exe        │                          │                  │
 │───────────────►│ 读取/生成序列号            │                  │
 │                │ 无授权 → 首屏=版本与试用     │                  │
 │ 点「申请 14 天试用」│                        │                  │
 │───────────────►│ 打开 /activate?serial=…   │                  │
 │                │─────────────────────────►│ 记录 pending      │
 │                │                          │ 渲染三个版本       │
 │                │                          │◄──── 点「申请」───│
 │                │                          │ 签发 14 天/3 次    │
 │                │                          │──── 深链/跳转 ───►│
 │                │◄──── 深链或 2.5s 轮询 ────│                  │
 │                │ 验签 → 写入授权 → 置顶窗口  │                  │
 │◄── 窗口到前台 ──│ 显示「试用中 · 剩余 14 天」 │                  │
```

异常分支：
- 浏览器拦截自定义协议 → 靠轮询，应用自己置顶；
- 服务不可达 → 版本页提示「未配置，请联系供应商」，按钮置灰；
- 机器码不匹配 → 官网返回「序列号已被其他设备使用」。

### 5.2 构建流程

```
选择项目 → 自动统计模块 → 配置算法/完整性/许可证 → 开始加密
   → 复制文件(10%) → 加密模块(15-60%) → 安装运行时(66%) → 写许可证(72%)
   → 写清单(78%) → 发布目录(84%) → 写密钥(88%) → manage.py check(92%)
   → 清理(96%) → 完成(100%)
```

## 9. 边界与已知限制（原型阶段可忽略，实现时需注意）

- 浏览器对 `pyshield://` 自定义协议的跳转需要用户手势，可能被拦截；应用会在授权到账后自动置顶兜底。
- 试用授权与本机机器码绑定，换机不可用；序列号仅用于索引，不承担安全职责。
- 发布版必须注入根公钥与站点地址，否则会退化为本地开发构建（自动起本地模拟站点）。
