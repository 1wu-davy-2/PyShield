      PyShield 加密构建器

      v—

      面向 Django 项目的离线源码保护工具。模块编译为字节码后使用 AEAD 信封加密，运行时在内存中解密，并通过 Ed25519 签名许可证与完整性清单校验部署环境。

      保护链路

      从源码到现场部署

      1. 01
        模块加密

        compile → marshal → zlib → AEAD，每模块独立派生密钥。

      2. 02
        运行时注入

        受保护模块由 stub 载入，解密后才进入内存。

      3. 03
        许可证签名

        Ed25519 签名，包含到期、宽限与设备绑定。

      4. 04
        完整性清单

        签名文件清单，部署后篡改会被启动校验拦截。

      安全边界

      了解工具的能力与限制

      可以做到

      阻止直接读取源码，发现文件篡改，控制许可证有效期与设备。

      无法绝对阻止

      主密钥必须内嵌在分发目录中，具备逆向能力的攻击者仍可提取。

      必须守住

      *.shield-secret.json 只留在构建方，泄露后可伪造许可证。

      源码保护用于提高逆向成本，不构成绝对 DRM。敏感业务请配合服务端鉴权与合同约束。
